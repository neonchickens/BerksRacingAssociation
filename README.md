# Berks Racing Association
## Rules, Regulations, Procedures, and Penalties
A place to track the evolving rules, regulations, procedures, and penalties for the Berks Racing Association. This serves both to centralize documentation and help change the rules for the better. Git is ideal for text document and rule change management.

These aim to provide consistency and fun across each race. However, the host makes all final decisions to how their race is run, regardless of outside opinion.
